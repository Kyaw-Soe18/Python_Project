# 🎓 Student Attendance Management System (UCSY)

## 📖 Overview

The **Student Attendance Management System** is a web-based application developed using **Python (Django)** for **University of Computer Studies, Yangon (UCSY)**.
The system is designed to simplify and digitize the process of managing student attendance by academic staff.

This system allows **Admins**, **Coordinators**, and **Teachers** to manage student data, assign subjects, and record attendance efficiently.

The main goal of this project is to:

* Reduce manual paperwork
* Improve accuracy of attendance records
* Provide quick access to attendance reports
* Enhance administrative efficiency

---

## ⭐ Key Features

* Role-based access control for **Admin**, **Coordinator**, and **Teacher**
* Secure login and authentication using Django
* Student information management (no student login access)
* Department, course, class, and subject management
* Subject assignment to teachers
* Daily attendance marking by teachers
* Automatic attendance percentage calculation
* Subject-wise, class-wise, and date-wise attendance reports
* Attendance monitoring and verification by coordinators
* Centralized database for accurate and consistent data storage
* Responsive and user-friendly web interface
* Scalable and modular system architecture
